# BRAND GUIDELINES — Trainings PRO

## Brand

- Nume platformă: **Trainings PRO**
- Issuer / parent brand: **NICPMS Academy**
- Domeniu: educație, training, certificare, programe profesionale și academice.

## Logo oficial

Logo-ul oficial este în:

```text
/public/brand/logo-trainings-pro-official.png
/public/brand/logo-trainings-pro-ppt-safe.png
/public/brand/logo-trainings-pro-ppt-safe.svg
```

În aplicație, folosește logo-ul în:

- header public
- sidebar /app
- sidebar /admin
- certificate
- pagini de verificare certificat
- documente exportate

## Stil vizual

- SaaS modern, premium, curat.
- Fundal principal: alb / gri foarte deschis.
- Accent: cyan, albastru, violet, magenta.
- Carduri albe, border fin, radius mare, shadow discret.
- Iconografie curată, educațională, tech.
- Layout cu sidebar pentru zonele interne.

## Font

Recomandare UI:

- Inter
- Geist Sans
- Arial fallback

## Logo usage rules

- Nu recrea logo-ul în componente UI.
- Folosește asset-ul din `/public/brand`.
- Nu adăuga pălărie, play icon sau alte simboluri peste versiunea finală.
- Păstrează monograma TP conectată.
- Pe fundal întunecat folosește PNG-ul transparent.
- Pe PowerPoint / documente externe folosește PNG-ul PPT-safe.
